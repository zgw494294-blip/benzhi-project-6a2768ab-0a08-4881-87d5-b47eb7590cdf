# seed-vault-admission

`seed-vault-admission` 是古树种子迁地保育材料的入藏资格评审工作台。它只处理一个明确流程：来源登记、分装建档、质量试验、异常整改、独立复核、保存清单冻结和入藏凭据签发。

服务由 Go 提供响应式 HTML、CSS、JavaScript 和同源 `/api/v1` JSON 接口，不需要 Node 或外部服务。所有写入都检查 `expectedVersion` 和 `idempotencyKey`；冻结后的批次拒绝修改，凭据可用编号及校验码核验。

草拟批次可在原工作台修订来源、修改或删除分装单元，并实时查看字段级提交预检、种子总数和净重合计。质量试验采用不可分叉的有效替代链，适宜性只使用每类试验的链尾结果。问题区支持最多 50 项整改证据原子提交；待复核队列支持物种、责任人、严重级别、状态筛选以及稳定游标分页。冻结前必须先预览规范化清单，再携带预览的 `batchVersion` 与 `previewDigest` 确认冻结。

## 构建

需要 Go 1.22 或更高版本。

```shell
go build ./cmd/server
```

## 运行

默认仅监听高位回环地址 `127.0.0.1:19081`：

```shell
go run ./cmd/server
```

可显式指定监听地址和数据目录：

```shell
go run ./cmd/server -addr=127.0.0.1:19120 -data=./local-data
```

未显式传入 `-addr` 时，也可以通过 `PORT` 提供端口号；服务将绑定 `127.0.0.1:<PORT>`。服务拒绝非回环地址和低于 `1024` 的端口。默认数据保存在 `.seed-vault-data`，包含长度前缀事件记录和原子投影快照。

启动后访问 `http://127.0.0.1:19081/`。工作台可完成批次创建与来源修订、分装清单维护、两类质量试验及复测替代、批量整改证据提交、待复核队列检索、问题复核、批次批准、冻结预览与摘要确认、凭据签发和打印核验。

## 测试与自检

运行全部回归测试：

```shell
go test ./...
```

运行有界 HTTP selfcheck：

```shell
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

selfcheck 使用真实监听器和公开 HTTP API，依次创建批次与分装单元，触发含水率严重问题，提交有效链尾复测和原子整改批次，由独立复核员关闭问题，再完成萌发试验、批次批准、冻结清单预览与摘要确认、凭据签发及核验，随后自动关闭服务并退出。自检数据使用临时目录，不会写入正式数据目录。

## 质量阈值与持久化

启动时固定的默认阈值为含水率 `3%` 至 `8%`、最低萌发率 `70%`、最大试验样本数 `10000`，试验时间不得早于 `365` 天前或明显晚于当前时间。

本地日志记录采用长度前缀 JSON 和 SHA-256 校验摘要；事件还包含连续序号、聚合版本、操作者、时间、前序摘要和自身摘要。截断的尾记录会安全移除，中段或摘要损坏会阻止写服务启动。投影快照通过临时文件同步后原子替换，并与日志位置、事件摘要和状态摘要交叉校验。
